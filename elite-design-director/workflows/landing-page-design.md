# Workflow: Landing Page (Persuade mode)

1. **Job and offer.** One primary action (as a transaction: "book a wash", "request a fleet quote"). One audience segment per page; if there are two, consider two pages. Traffic source (ad message match matters).
2. **Anxieties → proof map.** List the top 3–5 reasons not to convert and the real proof that answers each (`references/design-intelligence.md`).
3. **Research (Full tier for a complete landing page)** per `references/visual-research.md`. Query the exact page type and its key sections in this industry, plus out-of-category references. If the page belongs to an existing site, absorb the site's language first (`references/site-consistency.md` §1) so the synthesis stays inside it.
4. **Direction.** Write the 4-line Spec and the decision ledger, run the same-prompt test, draft divergent directions and pick a hero archetype (`design-generation.md`). Then the Direction Brief (`references/creative-art-direction.md` §7). Name the category rut and avoid it.
5. **Structure from the job** (`references/layout-and-composition.md` §5). Typical: Hero (what + for whom/where + action + real visual + one hard fact) → proof near the top → how it works / what you get → offer details and pricing → objections/FAQ → final action. 5–9 sections, one idea each.
6. **Copy first, then layout.** Headline ≈4–9 words, specific; supporting line ≤~20 words; CTA verb + object; a secondary action only if it serves a different readiness level (e.g., "See prices"). Write it per `references/copy-and-voice.md` (lexicon, headline method, section names in the brand's words); check it against `references/anti-ai-design.md` §Copy.
7. **Hero first.** Build and render the first viewport at 390×844 and 1440×900. CTA and headline visible at 1280×800. Memory test, swap test. Render 2 hero variants (different archetypes), then pick by looking. The fresh-eyes review (`agents/design-reviewer.md`) is mandatory before finishing.
8. **Sections.** Vary composition by content. One signature moment on the page. Real imagery (`references/imagery-and-visual-storytelling.md`).
9. **Conversion details.** Sticky mobile CTA if the page is long (not covering content); click-to-call on mobile for local services; form with minimal fields and an expectation line ("We reply within 2 hours"); trust signals next to the action; no exit popups by default.
10. **Performance.** LCP image optimized and prioritized; no heavy scripts above the fold; CWV targets.
11. **Verify and refine:** responsive + accessibility checklists, `consistency-audit.md` (Level B for the page, plus Level A against the site's other pages if it belongs to one), critique, refine, final gate. Include the research summary in the handoff. Report open content gaps (real photos, reviews, prices) as the top improvement lever.
