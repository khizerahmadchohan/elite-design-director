# Design Preflight (before designing)

- [ ] **Platform/stack identified** (WordPress+Elementor version/Pro, Woo, Shopify, React/Next, Tailwind, plain HTML). Existing component library noted.
- [ ] **Live vs staging vs local known.** Permission status for publishing/editing recorded.
- [ ] **Brand assets collected:** logo (SVG), colors, fonts, guidelines, existing DESIGN.md / Elementor Kit / theme tokens.
- [ ] **Brand situation classified:** established / incomplete / redesign / none.
- [ ] **Business model and primary conversion** stated in one line.
- [ ] **Audience, device context, anxieties** listed.
- [ ] **Surface mode** per page: Persuade / Operate / Read / Experience.
- [ ] **Real content inventory:** copy, photos, product screenshots, reviews (with source), prices, hours, address, certifications. Gaps listed.
- [ ] **Constraints:** must-keep elements, integrations, SEO URLs, legal text, deadlines, performance budget.
- [ ] **Scope and depth agreed:** component / page / site; polish / restyle / full redesign.
- [ ] **For redesigns:** preservation ledger started (links, forms, tracking, headings, media).
- [ ] **Direction Brief** written (Persuade/Experience) or a 3-line brief (Operate/Read).
