# Copy and Voice
Purpose: write interface and marketing copy in the business's own words so the page can't be mistaken for a competitor's.

Contents: §1 Voice axes · §2 Trade lexicon · §3 Headline method · §4 Section naming · §5 CTA rules · §6 Microcopy library · §7 Proof sequencing · §8 Message hierarchy · §9 Copy QA

Banned phrases and hype words: see `anti-ai-design.md` (Copy). Not repeated here.

## §1 Voice axes
Place the brand on each axis; write the two-word result into the Spec.

| Axis | Lean left when | Lean right when |
|---|---|---|
| Formal ↔ Casual | Regulated, high-stakes, older or B2B buyers | Consumer, community, owner-operated |
| Technical ↔ Plain | Buyers are practitioners who judge by specs | Buyers are first-timers or outsiders |
| Warm ↔ Precise | Care, hospitality, personal services | Engineering, finance, logistics |
| Bold ↔ Modest | Challenger with provable edge | Trust-led, conservative category |

| Voice result | Same message, written in that voice |
|---|---|
| Formal + precise | "Fleet accounts are invoiced monthly with itemised job sheets." |
| Casual + warm | "Run a fleet? We'll bill you once a month, every job listed." |
| Technical + bold | "Monthly invoicing. Per-axle line items. Export to CSV." |
| Plain + modest | "We can send one bill a month for all your trucks." |

Source the position from: how the owner talks, how customers write reviews, the category's norms (then deviate on one axis on purpose).

## §2 Trade lexicon method
1. Collect 15-25 real nouns and verbs from the business's world: reviews, invoices, job sheets, menus, forums, the owner's own speech.
2. Sort: objects (tools, parts, dishes), actions (detail, prep, torque, plate), units (bays, covers, axles), places.
3. Use them in headings, labels and CTAs. A heading with zero lexicon words is a candidate for rewrite.

Example (truck wash): bay, rig, trailer, axle, degrease, brightwork, fleet account, drive-through, pressure, chassis.

## §3 Headline method
Formula: **claim + concrete fact**.

| Rung | Example |
|---|---|
| Generic | "Quality cleaning you can trust" |
| Category | "Professional truck washing" |
| Specific | "Full rig wash, cab to mudflaps, in one bay" |
| Provable | "Tractor-trailer washed in 40 minutes, or the next one is free" |

Climb to the highest rung the facts support. Never invent the provable rung.

## §4 Section naming
Name sections in the brand's words, not template words.

| Template | Brand-word examples |
|---|---|
| Features | "What the bay does" · "Inside the app" · "On the bench" |
| Testimonials | "Drivers who came back" · "From the guest book" |
| Our Services | "The menu" · "Wash packages" · "What we fix" |
| About Us | "Who runs the shop" · "Since 1987" |
| FAQ | "Before you book" · "Questions fleets ask" |
| Contact | "Find the yard" · "Book a bay" |

## §5 CTA rules
- Verb + object: "Book a bay", "Get the quote", "Start a trial". Not "Submit", "Learn more", "Get started" alone.
- State the outcome or next step where useful: "Get a quote by email".
- Action-name consistency across the flow: the button, page title, toast and history all use the same verb ("Publish" → "Publishing…" → "Published").
- One primary CTA per view; secondary is visually subordinate.

## §6 Microcopy library
| Situation | Rule | Example |
|---|---|---|
| Form label | Noun, sentence case, visible (not placeholder-only) | "Fleet size" |
| Hint | Format or why we ask | "Number of trucks. Used for volume pricing." |
| Inline error | What went wrong + how to fix | "Enter a UK phone number, e.g. 07700 900123" |
| Empty — first use | What goes here + first action | "No jobs yet. Add your first vehicle to book." |
| Empty — no results | Echo query + recovery | "No bookings match 'Tuesday'. Clear filters." |
| Empty — filtered | Show filter state + reset | "3 filters on. Show all jobs" |
| Empty — no permission | Who can grant it | "Only account admins can view invoices. Ask Sam." |
| Empty — error | What failed + retry | "Couldn't load bays. Retry" |
| Confirm destructive | Name the object + consequence; verb button | "Delete 'Fleet A'? 12 bookings will be cancelled." [Delete fleet] |
| Loading | Specific, with count | "Saving 3 photos…" |
| Success | Past-tense same verb + where it went | "Booked. Confirmation sent to your email." |

## §7 Proof sequencing
Place each proof next to the decision it supports, answering a specific anxiety.

| Anxiety | Proof | Place next to |
|---|---|---|
| "Will it work for me?" | Case study from a similar customer | Feature/outcome claim |
| "Is it worth the price?" | Numbers, ROI, inclusions | Pricing |
| "Are they legit?" | Reviews with source, licenses, years trading | Hero or contact |
| "What if it goes wrong?" | Guarantee, refund, warranty terms | Primary CTA |
| "Is it hard to start?" | Setup steps, time-to-first-result | Signup/booking |

## §8 Message hierarchy per section
- One claim (heading), one support (a fact, image or proof), one action (link/CTA).
- If a section needs two claims, it's two sections.

## §9 Copy QA
- [ ] Read aloud; anything you wouldn't say to a customer, cut.
- [ ] Competitor-swap test: replace the brand name with a rival's; if the line still works, make it more specific.
- [ ] Every number has a source or is the client's own verified figure.
- [ ] No hype or virtue words (see `anti-ai-design.md`).
- [ ] No "Short claim. Another claim." fragment cadence repeated across headings.
- [ ] Lexicon words present in most headings.
- [ ] CTA verbs consistent through the flow.
